# c-basics

My first C programs — fundamentals exercises written while learning the language.

| File | What it does | Concepts |
| --- | --- | --- |
| [calculadora.c](calculadora.c) | Basic calculator (`+ - * /`) | `scanf`, `if / else`, arithmetic operators |
| [tabuada.c](tabuada.c) | Prints the multiplication table (1–10) of a number | `for` loop |
| [quente-frio.c](quente-frio.c) | Guess the random number (0–10) with higher/lower hints | `rand`, `srand`, `while` loop |
| [celsius-para-fahrenheit.c](celsius-para-fahrenheit.c) | Converts Celsius to Fahrenheit | arithmetic, `float` |

## How to run

```bash
gcc tabuada.c -o tabuada
./tabuada
```

> Prompts and variable names are in Portuguese. All programs compile on Windows (MinGW) and Linux.
